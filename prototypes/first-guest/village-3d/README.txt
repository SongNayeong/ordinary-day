첫 손님 — 나라가 처음 사주는 날
네 계절의 약속 · 이야기와 시범사용 개정판 / 2026-11-21

실행
index.html을 더블클릭해 Edge 또는 Chrome으로 엽니다.
별도 설치나 인터넷 연결 없이 실행됩니다. WebGL 그래픽 가속이 필요합니다.
이미 열려 있다면 새로고침합니다. 새 도입부부터 보려면 ‘새로운 일 년 시작’을 선택합니다.

국민에게 전하는 이야기
좋은 기술이 ‘써본 곳이 없다’는 이유로 멈추지 않도록,
조달청이 필요한 공공기관과 연결해 첫 구매와 사용 기록을 만듭니다.
그 이유는 새 기업을 돕는 것과 함께, 주민에게 필요한 공공서비스를 더 좋게 만들기 위해서입니다.

모리와 도담 할머니의 사계절
봄: 함께 걷고 싶은 숲길 — 작은 연기를 먼저 알아채기
여름: 할머니 댁으로 가는 길 — 위험한 지하차도를 닫고 안전한 길로 우회하기
가을: 혼자 가는 등굣길 — 작은 아이의 발걸음도 알아보기
겨울: 눈 오는 날의 안부 — 조용한 도움 요청을 복지관에 연결하기
주민의 편지 → 공공기관의 구체적인 필요 → 세 발명가의 발표 → 실제 시연
→ 첫 구매와 납품 → 사용 기록 세 장 → 개선 의견 → 주민의 답장과 다음 계절

현장에서 하는 일
연기를 클릭해 없애는 미니게임을 관찰·기록 방식으로 바꿨습니다.
소방서·도로관리센터·학교·복지관이 장비를 운용하고 대응합니다.
나르미는 세 시험 조건을 요청하고, 알림과 대응을 관찰해 사용 기록에 도장을 찍습니다.
기록을 잘못 골랐다면 다시 관찰할 수 있습니다. 재생도 가능하며 반사신경 제한시간은 없습니다.
새 기술의 헛경보, 드론의 강풍 약점, 기존 장비의 먼 구역 한계가 시험 결과에 나타납니다.
정확한 피드백을 받은 제품은 다음 계절 개선판의 성능이 실제로 좋아집니다.
새로 만난 기업의 제품은 별도의 첫 시험이 필요합니다.

조작
길 클릭 또는 WASD·방향키로 이동, Shift로 달리기, E로 대화합니다.
휴대폰은 왼쪽 아래 조이스틱으로 이동합니다. Esc 또는 Ⅱ로 일시정지합니다.
대화의 이어가기 버튼은 다음 장소로 걸어가는 동작까지 연결합니다.
‘편지와 약속 수첩’에서 왜 하는 일인지, 다음 목표와 보상을 확인할 수 있습니다.
발명가 세 명의 발표는 모두 순서대로 봅니다. 응원·질문·시연 반복으로 반응을 볼 수 있습니다.
구매 전에 선택한 제품의 실제 시연을 확인해야 합니다. AI의 분석은 근거와 대조해야 합니다.
주민·나무·분수를 눌러 반응을 볼 수 있습니다. 효과음은 일시정지 메뉴에서 끕니다.

저장과 목표
같은 브라우저에 자동 저장됩니다. 파일 주소나 브라우저를 바꾸면 저장이 이어지지 않을 수 있습니다.
이전 마을 버전의 예산·구매·기업 기록은 이어받습니다. 진행 중이던 옛 30초 미션은
재구매 없이 새 시범사용부터 시작합니다. 이전 저장은 별도 키에 보관합니다.
국민 안심 75 이상 + 혁신 성장 4 이상이면 재임명됩니다. 모두 게임 속 목표 수치입니다.
연말 리포트와 1080×1350 PNG 혁신 도감을 남길 수 있습니다.

소스와 검증
source 폴더에서 npm run build / npm test / npm run dev를 실행합니다. npm 설치는 필요 없습니다.
src/story.js: 이어지는 편지와 약속 / src/pilot.js: 시범사용·기록·결과 규칙
src/pilot-world.js: 기관 담당자, 출동·차단·횡단·방문 장면 / src/app.js: 화면과 진행
src/characters.js와 interaction.js: 관절 캐릭터·무대 발표·감정 반응
src/rules.js: 구매·예산·기업 성장 / src/nav.js: 길 찾기
src/engine.js는 이전 버전 호환 검증을 위해 남긴 옛 미션 원본이며 새 게임에는 포함하지 않습니다.
그 밖의 기존 화면·동영상은 이전 동작 개정판 자료입니다.

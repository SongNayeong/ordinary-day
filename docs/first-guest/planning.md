## 3. 기본 규칙 (이게 전부)
| 번호 | 규칙 |
|---|---|
| [R1] | 내 턴: 카드 1장 뽑기 → **예산**만큼 카드 내기 → 판에 있는 내 기술로 재난 카드나 재난 대장을 **처리**(공격) → [턴 끝내기] |
| [R2] | 예산은 1에서 시작해 **매 턴 +1, 최대 6** |
| [R3] | 처리하면 서로의 **대응력만큼 튼튼함이 깎임**. 0이 되면 판에서 사라짐 |
| [R4] | 재난 턴: 재난 카드를 내고, 재난들이 **마을**이나 내 기술을 공격 |
| [R5] | 재난 대장의 **힘 0 → 승리** (그 계절을 지켜냄) / **마을 안심 0 → 패배** → 바로 다시 도전 (벌칙 없음, 대신 ✉️ 고칠 점 편지 1장 보너스) |
| [R6] | 판에 낸 기술은 **낸 다음 턴부터** 처리 가능 (⚡ 즉시 출동 제외) |

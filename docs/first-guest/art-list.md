| [R2] | 캐릭터·제품·물건은 **투명 배경 PNG** | 게임 화면 위에 올려야 함 |

### 스타일 — 조달청 공식 2D 그림체에 맞춤 (2026-11-20 변경)
> 조달청 공식 캐릭터 자료를 확인한 결과, 나르미·달이는 **굵은 검정 외곽선 + 단순한 면 채색의 2D 그림체**가 기본이고 정면·옆·뒤 모습(턴어라운드)까지 있음
> 3D 이미지는 한 포즈뿐이라, 게임 전체는 **공식 2D 그림체**로 통일하고 3D 이미지는 타이틀·엔딩에서만 특별하게 사용

**모든 프롬프트 앞에 붙일 공통 문장 (복사해서 사용)**
```
귀여운 2D 캐릭터 일러스트, 굵고 깔끔한 검정 외곽선, 단순한 면 채색(그라데이션 거의 없음), 둥글고 통통한 2등신 비율, 작은 점 눈, 파스텔 색감(하늘색, 민트, 버터 노랑, 피치, 연한 주황), 마스코트 스티커 같은 느낌, 그림 안에 글자나 로고 없음
```
- GPT에 첫 메시지를 보낼 때 **공식 나르미·달이 그림(`character1.png` 턴어라운드)을 함께 올리고** *"이 그림과 같은 선 굵기·채색 방식으로"*라고 하면 가장 잘 맞음
- 캐릭터·제품·물건이면 끝에 추가: `투명 배경, 정면에서 살짝 위, 가운데 배치`
- 현장 배경이면 끝에 추가: `위에서 비스듬히 내려다본 2D 지도 일러스트, 16:9 가로 화면, 가운데는 비교적 단순하게 비워둠`

## 1. 공식 캐릭터 나르미·달이 (GPT로 그리지 않음)

### 확인 결과
- 조달청 **공식 캐릭터는 나르미·달이 둘뿐**. "서포터즈" 같은 다른 공식 캐릭터는 조달청 누리집·보도자료에서 찾지 못함
- 공식 자료 (조달청 누리집 > 기관 상징(CI) > 상징물):
  - **기본형**: 나르미·달이가 나란히 선 2D 그림
  - **응용형**: 나르미·달이 **정면·옆·뒤** 2D 턴어라운드
  - 공모전 제공 파일: `조달청 나르미와 달이 3D.png`, `나르미 & 달이 캐릭터 소개.ai`
